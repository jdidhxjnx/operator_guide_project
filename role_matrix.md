# Матрица ролей учебного сервиса заявок

В таблице отражены действия целевых ролей (Оператор и Техник) в соответствии со спецификацией SPEC-1.0. Действия администратора (manager_a) вынесены за пределы руководства оператора.

## Действия ролей

| Роль | Создание заявки | Чтение заявок | Редактирование | Смена статуса | Удаление |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Оператор** (`operator_a`, `operator_b`) | Да | Только собственные | Только собственные открытые заявки | Нет | Нет |
| **Техник** (`technician_a`) | Нет | Только назначенные ему | Нет | Да (`open` → `in_progress` → `resolved`) | Нет |
| **Менеджер** (`manager_a`) | Нет | Все заявки | Нет | Назначает исполнителя | Нет |
| **Неавторизованный** | Нет | Нет | Нет | Нет | Нет |

## Важные ограничения

1. **Права доступа:** Доступ ограничивается на стороне сервера. Если вы не видите какую-то кнопку на экране, это не значит, что действие разрешено — это значит, что у вас нет прав на это действие.
2. **Смена статуса:** Техник может переводить заявку в статус `resolved` (выполнена) только при наличии непустого комментария.
3. **Редактирование:** Оператор может редактировать только свои заявки, пока они находятся в статусе `open`.
4. **Удаление:** Ни одна из целевых ролей не имеет права удалять заявки. Закрытие без записи истории запрещено.
